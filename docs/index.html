安装

# Claude Code
git clone git@github.com:occultskyrong/yibasuo-skill.git /tmp/yibasuo-skill
cd /tmp/yibasuo-skill && bash install.sh

# Codex
bash install.sh --codex

安装后说 一把梭 即可触发。7 个 Agent + 4 套 Rules 全部内置，零外部依赖。

⚠ Token 消耗说明
一把梭会显著增加 API 调用量——每个阶段调用内置 Agent 独立分析。新功能 ~90K tokens (3.5x)，Bug 修复 ~40K (3x)。多的成本换来架构评审 + 强制 TDD + 代码审查 + 安全审查 + 提交前验证。改一行文字不建议使用。

运行模式

自动 · 默认

阶段 0-4 连续执行，仅提交前确认。适合信任度高的常规任务。

一把梭 全流程 梭哈

交互 · 显式触发

每阶段暂停等待确认。适合复杂需求、高风险变更。

一步步梭 交互梭 确认梭

行为红线

01

编码前思考

不确定时提 2-3 种解释，不默默假设

02

简洁优先

最少代码解决问题，不添加未请求的功能

03

手术刀改动

只改任务相关代码，死代码只提不删

04

循环验证

每阶段定义成功标准，不达标不回

05

破坏性变更需确认

删文件/代码/表结构前告知原因和影响

06

前端校验不替代后端

后端不信任前端任何数据，全部重校验
